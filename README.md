HR Analytics Dashboard

Project Overview

This Power BI HR Analytics Dashboard provides detailed insights into employee data, attrition, demographics, job roles, job satisfaction, and salary information.

The dashboard helps analyze employee performance, identify attrition patterns, and understand workforce trends using interactive visualizations.

Dashboard Features

HR Analytics Dashboard

1- Total Employees
2- Total Attrition
3- Attrition Rate
4- Active Employees
5- Average Employee Age
6- Average Monthly Pay

Employee Analysis

1- Employee by Age Group and Gender
2- Total Attrition by Age
3- Department-wise Attrition
4- Attrition Rate by Job Role
5- Job Satisfaction Rating
6- Total Attrition by Education Field

Interactive Filters

1- Education
2- Gender
3- Marital Status
4- Business Travel

Tools & Technologies

1- Power BI
2- Microsoft Excel
3- Data Cleaning
4- Data Analysis
5- Data Visualization
6- DAX
